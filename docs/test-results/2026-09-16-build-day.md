## Failures found and fixed during the build (each became a test)

1. Dependency-name segmentation swallowed a known name into an unknown fragment → tiebreak minimises unresolved parts.
2. Per-module ESLint override replaced the base boundary rule (a `react` import inside `core/agent` passed) → rules composed; probed in three modules.
3. `FlightPlan` brand declared as a type-only symbol → runtime `ReferenceError`; now a module-private `Symbol`.
4. Providing hours did not clear `pending` → run loop never resumed.
5. Exclusions did not prune the excluded node's subtree.
6. External-change handling raced the run loop → loop stops on `STALE` and merges in-flight step results; `engine.idle()` for tests.
7. Weakening the engine's policy set changed nothing because the resolver derived requirements independently → closure rules now derive from the engine's policy set, so a weakened engine misbehaves and the evaluator catches it.
8. Stale Turbopack CSS chunk hid new colour tokens → clean restart; documented.
